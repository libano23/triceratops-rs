Using Triceratops

A practical guide to the modeller: how to give commands, move around the model, build curves, surfaces and solids, design with Locust, and let an AI assistant model for you.

Getting started

Download the build for your system from the download section or the latest release:

SystemFileHow to start
Linux (x86_64)Triceratops-<version>-x86_64.AppImagechmod +x it, then run it
Windows 10/11Triceratops-<version>-windows-x64.zipUnzip and run triceratops.exe
macOS 11+Triceratops-<version>-macos-universal.dmgDrag it to Applications; the first time, right-click it and choose Open

The window

  • Menu bar at the top, with every command grouped by kind (Curve, Surface, Solid, Mesh, Transform, Analyze, …).
  • Command area: the history of what you did, and the command line where you type.
  • Toolbars in tabs (Standard, CPlanes, Set View, Display, Curve Tools, Solid Tools, …) and the sidebar on the left. Buttons with a small triangle open a flyout of related commands.
  • Viewports: Top, Front, Right and Perspective by default. Their title is a menu (views, display modes, layouts).
  • Panels on the right: Properties, Layers and more. Drag a tab out to float it, or use its ▾ menu to dock it elsewhere.
  • Status bar: cursor coordinates, the current layer, and Grid Snap, Ortho, Planar, Osnap and Gumball toggles. Above it sits the bar of object snaps.

The command line

Everything in Triceratops is a command: type its name (Box, Loft, BooleanDifference, …) and press Enter, or click a button. The command then asks for what it needs, one prompt at a time.

  • Points: click in a viewport (snaps help), or type coordinates such as 10,20,0.
  • Numbers: type them; a default shown in angle brackets <5> is taken with Enter.
  • Options appear in parentheses after the prompt, for example ( DeleteInput=Yes ): click one or type its name.
  • Objects: select them in a viewport and press Enter, or select first and then start the command.
  • Enter or a right-click in a viewport finishes a list (points of a polyline) or repeats the last command when none is running. Esc cancels.

Typing a few letters autocompletes; Help (F1) describes commands. About 1,070 commands are registered.

Display modes (Wireframe, Shaded, Rendered, Ghosted, X-Ray, Technical, Arctic, Pen, and analysis modes like Zebra, Curvature and Draft Angle) are in each viewport's title menu and in the Display tab.

Selecting

  • Click an object to select it; Shift+click adds, Ctrl+click removes.
  • Window: drag from left to right to select what is fully inside the rectangle.
  • Crossing: drag from right to left to select everything the rectangle touches.
  • Ctrl+A selects all, Esc deselects, Delete deletes.
  • Control points: F10 shows them for the selected curves and surfaces, F11 hides them. Drag them, or select them and use Move.

Drawing aids

  • Object snaps (the bar above the status bar): End, Near, Point, Mid, Cen, Int, Perp, Tan, Quad, Knot, Vertex. Turn them on there; Osnap in the status bar switches them all.
  • Grid Snap (F9) and Ortho (F8, or hold Shift while picking) keep points on the grid and on the axes. F7 shows or hides the grid.
  • Planar keeps new points at the height of the previous one.
  • Gumball: arrows, arcs and squares on the selection move, rotate and scale it by dragging.
  • Construction planes (CPlanes tab): every viewport draws on its own plane; set one from three points, an object or the view.

Modelling

Curves

Line, Polyline, Circle, Arc, Ellipse, Rectangle, Polygon, Helix, interpolated (InterpCrv) and control-point (Curve) curves; then Fillet, Offset, Trim, Split, Join and Rebuild.

Surfaces

ExtrudeCrv, Revolve, Loft, Sweep1, Sweep2, NetworkSrf, EdgeSrf, Patch, PlanarSrf and BlendSrf. Curves projected or pulled onto surfaces trim and split them.

Solids

Box, Cylinder, Sphere, Cone, Torus; Cap closes open polysurfaces. BooleanUnion, BooleanDifference, BooleanIntersection and BooleanSplit keep the original surfaces and only add trim curves. FilletEdge, Shell, RoundHole, WireCut and PushPull edit solids.

Organising

Layers (Layers panel or the status bar) carry colour, visibility and locking. Group, Hide (Ctrl+H), Lock (Ctrl+L). With Record History on, objects made from others follow when you edit their parents.

Measure with Length, Area, Volume and Distance; check with Zebra, CurvatureAnalysis and DraftAngleAnalysis.

Long operations

Booleans and other heavy operations run in the background. The window stays responsive, so you can still orbit and zoom. The status bar shows a spinner, the elapsed time, the stage and a counter, for example BooleanUnion — 12 s · mesh Boolean · 1.3 M · Esc to cancel.

  • Esc (or the Cancel button in the status bar) stops it; the model stays as it was.
  • While it runs, other commands wait; a history update that needs a Boolean runs the same way.
  • A Boolean that would need too much memory stops with Boolean too complex: simplify the inputs or use a coarser mesh.

Files

Ctrl+O opens, Ctrl+S saves. The native format is .3dm (openNURBS), with layers, names, colours, units and blocks.

Locust: visual programming

Locust builds models from a graph of components, so they stay parametric: change a slider and the model is rebuilt. Type Locust (or lc) to open the editor.

  1. Add components: double-click the canvas, or use Add component, and type part of a name (Circle, Extrude, Voronoi, …). There are more than 200: numbers and maths, lists and data trees, vectors, curves, surfaces, solids, meshes, transforms and analysis.
  2. Wire an output (right side of a component) to an input (left side) by dragging. Unwired inputs show a slider or a field for their value.
  3. See the result: anything wired to Preview is drawn in the viewports, in red, as you edit. Panel shows the data flowing through a wire. Hover over a port to see its values.
  4. Bake turns what reaches a Bake component into ordinary objects you can keep modelling with.
  • Solves run in the background: dragging a slider restarts them, the last result stays on screen, Esc stops a long one.
  • A red or orange dot on a component means an error or a warning: hover over it to read why.
  • Select components to group (Ctrl+G) them, add comments, or make a cluster: a sub-graph shown as one component.
  • Examples menu: an M10 screw with its nut, an involute gear (spur or helical), a surface from an equation, Voronoi tiles and cells on a surface, and a dovetail joint. Open one and change its sliders.
  • The canvas is kept between sessions; Save… and Open… store definitions as .locust files.

Script and Expression nodes

Expression computes a formula of its inputs (x, y, z by default), once per item: type the formula on the node. Angles are in radians; PI, E, deg(), rad(), pow, atan2, min, max and clamp are available.

sin(x) * cos(y)          // a wave surface, with x and y from two Series
pow(x, 2) + 1
if x > 0 { x } else { 0 }

Script runs code in Rhai, a small language with a Rust- and JavaScript-like syntax. Right-click the node to add, rename or remove inputs and outputs. Double-click the node to edit the code. Inputs are variables, and whatever each output variable holds at the end comes out; an array comes out as a list. An input's Access chooses item (the code runs once per item), list (the whole list) or tree.

// inputs n (number of points) and r (radius), output a
a = [];
for i in 0..n {
    let t = 2.0 * PI * i / n;
    a.push(point(r * cos(t), r * sin(t), 0));
}

Geometry helpers include point and vec (with + - * /, dot, cross, length, unit), line, polyline, interpolate, circle, arc, helix, loft, extrude, revolve, sweep1, cap, surface_from_grid, box, cylinder, sphere, union, difference, intersection, move, rotate, scale, mirror, array_polar, area, volume and rng(seed).next(). run("Component", [inputs]) calls any component by name. print() shows text on the node.

Functions you define with fn only see their parameters: inside them write PI() instead of PI. Scripts cannot read or write files, start programs or use the network, and an endless loop stops with an error.

AI assistants (MCP)

Claude, Codex and other MCP clients can model in the window you have open. Register Triceratops once, using the executable you run:

# Claude Code
claude mcp add triceratops -- ~/Applications/Triceratops.AppImage mcp
# Codex
codex mcp add triceratops -- ~/Applications/Triceratops.AppImage mcp

On Windows use C:\path\to\triceratops.exe mcp, and on macOS /Applications/Triceratops.app/Contents/MacOS/triceratops mcp. Then ask, for example:

  • "Make a 60×40×8 mm plate with two 6 mm holes 40 mm apart." The assistant runs commands and gives you fixed geometry.
  • "Build a parametric M8 bolt and nut in Locust." or "A gear where I can change the number of teeth." The assistant builds a Locust definition, and you keep adjusting it with the sliders.

You choose which of the two it uses. The assistant can look at a viewport image, measure volumes, undo, and stop a long operation with cancel; it shows progress while a Boolean or a solve runs. Everything it does can be undone.

Only programs running as you on the same computer can connect; nothing listens on the network. Options › AI Assistants switches it off. Requests wait while you are typing or running a command of your own, and file commands (Open, Save, Export) are not available to assistants.

Command scripts

A script file holds one command-line entry per line, exactly as you would type it. An empty line presses Enter, and _Cancel presses Esc. Objects are named #12, #12@x,y,z (picked at a point) or last (what the last command made).

0,0,0
60,40,0
8
Cylinder
15,20,-1
3
10
BooleanDifference
#1
#2

Run one with ReadCommandFile, or start the program with triceratops --script commands.txt.

Settings

  • Snaps, Ortho, Grid Snap, Planar, Gumball, the window layout, the theme and the export folders are saved automatically. Options › Appearance saves or loads a layout and resets to the defaults.
  • Theme (or View › Theme) switches between Triceratops Light, Triceratops Dark and Blender; your own themes are JSON files in <config>/triceratops/themes.
  • Settings live in <config>/triceratops/options.json, where <config> is ~/.config on Linux, %APPDATA% on Windows and ~/Library/Application Support on macOS.

Troubleshooting

  • Graphics problems: start with TRICERATOPS_BACKEND=gl (or vulkan) to pick the graphics backend.
  • macOS says the app cannot be opened: it is not notarized; right-click it in Applications and choose Open the first time.
  • A Boolean fails: check that both objects are closed solids (What or the Properties panel). TRICERATOPS_BOOL_DEBUG=1 prints diagnostics to the terminal.
  • Something feels slow: TRICERATOPS_SLOW=1 names any command step that takes over a second.
  • Found a bug? Open an issue with the steps or a command script that shows it.
